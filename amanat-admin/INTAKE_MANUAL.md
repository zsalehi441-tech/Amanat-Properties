# Media Intake Manual (HQ Use Only)

## Overview
The "Media Intake" page in the Admin Panel allows you to upload photos and documents directly to the secure Amanat Media Service.

## Access
1. Open Strapi Admin.
2. Click **Media Intake** in the left sidebar.

## Tabs

### 1. Property Photos
- **Purpose**: Upload photos for listings (Residential/Commercial/Land).
- **Process**:
  1. Click "Choose File" and select an image (JPG, PNG).
  2. Wait for the upload to finish.
  3. **Success**: You will see a thumbnail and the IDs/URLs.
  4. **Action**: Copy the **Thumb URL** or **Full URL** and paste it into the listing form in Content Manager.

### 2. Documents (Private)
- **Purpose**: Upload sensitive docs (Qabala, ID cards).
- **Process**:
  1. Click "Choose File" (PDF or Image).
  2. Wait for upload.
  3. **Success**: You will see a **Document ID**.
  4. **Note**: There is NO public URL. These are stored securely.
  5. **Action**: Copy the **Document ID** and paste it into the secure "Documents" field in the listing (if applicable).

## Troubleshooting
- **Error: "No file uploaded"**: Retry selecting the file.
- **Error: "Unauthorized"**: Contact IT (API Key issue).
- **Spinner stuck**: Refresh the page.
