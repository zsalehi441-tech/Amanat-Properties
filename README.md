# Amanat Real Estate

## Project Structure

- **amanat-web**: Public website (Vite/React)
- **amanat-admin**: HQ Admin System (Strapi)
- **amanat-media**: Local media pipeline (Placeholder)

## Quick Start

Run the following commands from the root directory:

### Run Locally

- **Web Client**:
  ```bash
  npm run dev:web
  ```
- **Admin Server**:
  ```bash
  npm run dev:admin
  ```
- **Both**:
  ```bash
  npm run dev
  ```

### Build

- **Web Client**:
  ```bash
  npm run build:web
  ```
- **Admin Server**:
  ```bash
  npm run build:admin
  ```
